````mermaid
flowchart TD
    Start[请求获取详情 ID] --> L1{查 L1 缓存 Caffeine}
    L1 -- 命中 --> End_L1[更新热点/叠加状态返回]
    L1 -- 未命中 --> L2{查 L2 缓存 Redis}
    
    L2 -- 命中 --> End_L2[解析回填 L1 并返回]
    L2 -- 未命中 --> Lock[获取 SingleFlight 锁并排队]
    
    Lock --> DCL{排到队后: Double Check Redis}
    DCL -- 已有缓存 --> End_DCL[被其他线程代劳, 直接返回]
    DCL -- 依然没有 --> DB[查询 MySQL 数据库]
    
    DB --> CheckNull{数据为空或已删除?}
    CheckNull -- 是 --> CacheNull[Redis 缓存 NULL 防止穿透] --> Throw404[抛出异常]
    CheckNull -- 否 --> Perm{权限校验 isPublic/isOwner}
    
    Perm -- 无权限 --> Throw403[抛出异常 🚨注:此处有DDOS漏洞]
    Perm -- 有权限 --> Build[组装详细数据]
    
    Build --> Jitter[计算 TTL + 随机 Jitter 防止雪崩]
    Jitter --> WriteCache[写入 Redis & Caffeine]
    WriteCache --> Unlock[释放 SingleFlight 锁🚨注:需finally]
    Unlock --> Return[返回最终数据]
