````mermaid
flowchart TD
    Start([请求 getDetail])
    L1Cache{1. 查询 L1 缓存<br/>Caffeine}
    L1Auth{L1 缓存命中<br/>2. 鉴权 isAuthorized}
    ThrowL1Auth((抛出无权限异常))
    L1HotKey[记录热点并续期]
    L1Enrich[叠加实时状态 enrich]
    EndL1([返回数据])

    L2Cache{3. 查询 L2 缓存<br/>Redis}
    TryProcess[4. 执行 tryProcessCacheHit]
    ThrowNull1((抛出内容不存在))
    Fallback[视为未命中]
    ThrowL2Auth((抛出无权限异常))
    L2Enrich[叠加实时状态 enrich]
    EndL2([返回数据])

    Lock[5. 获取 SingleFlight 锁排队]
    TryBlock[["进入 try { ... } 保护区"]]
    DCL{6. Double-Check<br/>再次查 Redis}
    TryProcess2[执行 tryProcessCacheHit]
    EndDCL([返回数据])

    DB[7. 查 MySQL 数据库]
    CheckDB{数据是否存在}
    WriteNull[8. 写入 NULL 缓存防穿透]
    ThrowNull2((抛出内容不存在))

    Build[9. 组装基础视图对象]
    IsPublic{10. 核心隔离策略<br/>是否完全公开}
    WriteCache[11. 算动态TTL+Jitter<br/>写入 Redis 和 L1]
    AuthDB{12. 最终鉴权拦截}
    ThrowDBAuth((抛出无权限异常))
    DBEnrich[13. 叠加实时状态 enrich]
    EndDB([返回数据])

    FinallyBlock[["finally { 释放锁 singleFlight.remove }"]]

    Start --> L1Cache
    L1Cache -- 命中 --> L1Auth
    L1Auth -- 无权限 --> ThrowL1Auth
    L1Auth -- 有权限 --> L1HotKey
    L1HotKey --> L1Enrich --> EndL1

    L1Cache -- 未命中 --> L2Cache
    L2Cache -- 命中 --> TryProcess
    TryProcess -- 命中NULL --> ThrowNull1
    TryProcess -- 反序列化失败 --> Fallback
    TryProcess -- 无权限 --> ThrowL2Auth
    TryProcess -- 成功且有权 --> L2Enrich --> EndL2

    L2Cache -- 未命中 --> Lock
    Fallback --> Lock

    Lock --> TryBlock
    TryBlock --> DCL
    DCL -- 已被他人写入 --> TryProcess2 --> EndDCL

    DCL -- 仍未命中 --> DB
    DB --> CheckDB
    CheckDB -- 否/已删除 --> WriteNull --> ThrowNull2
    CheckDB -- 是 --> Build
    Build --> IsPublic
    IsPublic -- 是 (Public) --> WriteCache --> AuthDB
    IsPublic -- 否 (Private等) --> AuthDB

    AuthDB -- 无权限 --> ThrowDBAuth
    AuthDB -- 有权限 --> DBEnrich --> EndDB

    TryBlock -.-> FinallyBlock
    EndDCL -.-> FinallyBlock
    EndDB -.-> FinallyBlock
    ThrowNull2 -.-> FinallyBlock
    ThrowDBAuth -.-> FinallyBlock
