````mermaid
sequenceDiagram
autonumber
participant Client as 客户端 (前端)
participant QueryService as RagQueryService
participant IndexService as RagIndexService
participant DB as 数据库/OSS
participant VectorStore as 向量数据库 (Elasticsearch)
participant LLM as 大模型 (DeepSeek)

    Client->>QueryService: 1. 发起提问 streamAnswerFlux(postId, query)
    activate QueryService

    %% 第一阶段：索引保障
    Note right of QueryService: 第一阶段：前置索引保障 (保障回答有据可依)
    QueryService->>IndexService: 2. ensureIndexed(postId)
    activate IndexService
    
    IndexService->>DB: 3. 查库校验 (检查文章是否存在、公开、有效)
    IndexService->>IndexService: 4. 文章指纹判重
    
    alt 指纹未变 (已建过索引)
        IndexService-->>QueryService: 直接返回，跳过向量化 (节省算力)
    else 首次索引或文章有更新
        IndexService->>IndexService: 5. 文本切片 getChunks<br>(每块 max 800 字符，保留 100 字符重叠)
        IndexService->>VectorStore: 6. 调用 Embedding 转为向量并写入 ES
        IndexService-->>QueryService: 索引构建完成
    end
    deactivate IndexService

    %% 第二阶段：语义检索
    Note right of QueryService: 第二阶段：精准语义检索 (防幻觉与防 OOM)
    QueryService->>VectorStore: 7. 发起相似度检索 similaritySearch
    Note over QueryService, VectorStore: 核心调优：<br>1. 过滤条件下推 (filter: postId == xxx)<br>2. 相似度阈值拦截 (threshold >= 0.7)<br>3. 限制召回数量 (topK)
    
    activate VectorStore
    VectorStore-->>QueryService: 8. 返回高相关性的 Document 切片列表
    deactivate VectorStore
    
    QueryService->>QueryService: 9. 提取 getText() 并过滤无效空文本

    %% 第三阶段：大模型生成与流式推送
    Note right of QueryService: 第三阶段：大模型推理与流式响应 (SSE)
    QueryService->>LLM: 10. 组装 Prompt (上下文切片 + 用户提问)<br>调用 ChatClient 发起对话
    activate LLM
    
    Note over QueryService, LLM: 建立长连接，等待模型逐字吐出 Token
    LLM-->>QueryService: 11. 返回响应流 Reactor Flux<String>
    deactivate LLM
    
    QueryService-->>Client: 12. 以 SSE 形式逐字推送给前端 (打字机体验)
    deactivate QueryService
