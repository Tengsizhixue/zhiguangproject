````mermaid
flowchart TD
    Start([开始: 调用 getCounts]) --> Step1[1. 尝试读取 SDS 固定字节数组]
    Step1 --> CheckNeedRebuild{SDS 是否缺失或损坏?}

    %% 正常命中缓存分支
    CheckNeedRebuild -- "否 (缓存健康)" --> ParseSDS[3. 解析 SDS 字节数组]
    ParseSDS --> EndSuccess([返回真实计数 Map])

    %% 重建分支
    CheckNeedRebuild -- "是 (需重建)" --> CheckBackoff{2.1 触发退避拦截?}
    
    CheckBackoff -- "是" --> ThrowBusy1([抛出 SYSTEM_BUSY 异常])
    CheckBackoff -- "否" --> CheckRateLimit{2.2 触发令牌桶限流?}
    
    CheckRateLimit -- "是" --> EscalateBackoff[加重退避惩罚] --> ThrowBusy2([抛出 SYSTEM_BUSY 异常])
    CheckRateLimit -- "否" --> TryLock[2.3 尝试获取分布式锁<br>tryLock 等待200ms]
    
    TryLock --> IsLocked{是否获取到锁?}
    IsLocked -- "否 (等待超时)" --> ThrowBusy3([抛出 SYSTEM_BUSY 异常])
    
    IsLocked -- "是 (抢锁成功)" --> DoubleCheck[2.4 Double-Check<br>再次读取 SDS]
    DoubleCheck --> IsDoubleCheckOK{SDS 已被其他线程建好?}
    
    IsDoubleCheckOK -- "是 (白嫖别人的成果)" --> ResetBackoff1[重置退避状态] --> ParseSDS
    
    IsDoubleCheckOK -- "否 (依然缺失)" --> LoopMetrics[2.5 遍历 SUPPORTED_METRICS 中<b>所有</b>指标]
    LoopMetrics --> Bitcount[底层管道批量 BITCOUNT 获取真实值]
    Bitcount --> WriteArray[写入 newSds 字节数组对应的偏移量]
    WriteArray --> SetRaw[2.6 回写完整 SDS 到 Redis]
    
    SetRaw --> CheckClean{是否有字段被重建?}
    CheckClean -- "是" --> CleanAgg[2.7 删除 Redis Hash 聚合桶临时增量]
    CheckClean -- "否" --> ResetBackoff2[2.8 重置退避状态]
    CleanAgg --> ResetBackoff2
    
    ResetBackoff2 --> ReleaseLock[finally: 释放锁 unlock]
    ReleaseLock --> EndSuccess
