````mermaid
sequenceDiagram
    participant Java as Java应用端 (UserCounterService)
    participant Redis as Redis 主线程
    participant Lua as Lua 脚本引擎
    participant SDS as 底层 SDS 内存块 (20字节)

    Note over Java,SDS: 场景：给用户粉丝数 (索引2) 增加 1
    Java->>Redis: redis.execute(Lua脚本, key, 参数:[idx=2, delta=1])
    
    Note over Redis: 开启独占模式 (单线程)<br/>阻塞其他所有并发请求，保证绝对原子性
    
    Redis->>Lua: 载入并运行 Lua 脚本，传入参数
    
    Lua->>SDS: 发起查询：redis.call('GET', key)
    alt Key 存在
        SDS-->>Lua: 返回现有的 20 字节二进制数据
    else Key 不存在
        Note over Lua: 内存初始化
        Lua->>Lua: 在内存中凭空生成 20 字节的 0 (初始化药盒)
    end

    Note over Lua: 步骤 1【找位置】：<br/>计算偏移量 off = (2-1)*4 = 4 字节
    Note over Lua: 步骤 2【提取】：<br/>切出第 5 到 8 字节的数据
    Note over Lua: 步骤 3【计算】：<br/>用 read32be 将字节还原为十进制数字，加上增量 1
    Note over Lua: 步骤 4【压缩】：<br/>用 write32be 将新数字重新压扁成全新的 4 字节块
    Note over Lua: 步骤 5【缝合】：<br/>string.sub(保留前4字节) + 新4字节 + string.sub(保留后12字节)
    
    Lua->>SDS: 发起保存：redis.call('SET', key, 拼接好的新20字节)
    SDS-->>Lua: 覆盖保存成功
    
    Lua-->>Redis: 脚本执行完毕，返回结果 1
    Note over Redis: 释放独占模式，继续处理其他网络请求
    Redis-->>Java: 返回成功信号
