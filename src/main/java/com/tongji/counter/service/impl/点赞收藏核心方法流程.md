````mermaid
sequenceDiagram
    autonumber
    participant Client as 客户端 (用户界面)
    participant App as 业务服务器 (Service)
    participant Redis as Redis (Lua脚本)
    participant Spring as Spring本地监听器
    participant Kafka as Kafka消息队列
    participant Aggregator as 聚合消费者集群
    participant MySQL as 关系型数据库

    Client->>App: 发起互动请求 (点赞/收藏)
    activate App
    App->>App: BitmapShard.chunkOf(uid)<br>计算分片与偏移量
    App->>Redis: 发送 Lua 脚本与参数 (GETBIT & SETBIT)
    activate Redis
    Note over Redis: 保证原子性，其他线程排队
    
    alt 状态未变化 (重复点赞)
        Redis-->>App: 返回 0L
        App-->>Client: 返回成功 (忽略重复动作)
    else 状态发生翻转 (有效点赞)
        Redis-->>App: 返回 1L
    end
    deactivate Redis

    opt 返回值为 1L 时执行
        App->>Kafka: 发送增量事件 (delta: +1/-1)
        Note over Kafka,Aggregator: 异步处理：聚合一段时间内的变化量，降低DB写压
        Aggregator->>Kafka: 批量拉取消息
        Aggregator->>MySQL: 执行 UPDATE 最终落盘

        App->>Spring: 发出本地事件 (ApplicationEvent)
        Note over Spring: 极速响应：清理或修改本地 JVM 及 Redis 页面缓存
        Spring-->>App: 缓存更新完毕
    end
    
    App-->>Client: 返回处理结果 (UI更新)
    deactivate App
