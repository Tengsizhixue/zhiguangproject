````mermaid
sequenceDiagram
    autonumber
    participant Client as 业务线程 (如 Tomcat)
    participant Redis as Redis (SDS结构)
    participant Redisson as Redisson 分布式锁
    participant Bitmap as Redis (底层位图分片)

    Client->>Redis: 1. GET 抓取 20字节 SDS 数据
    Redis-->>Client: 返回 raw byte[]

    alt SDS 完美命中 (长度正确且不为空)
        Client->>Client: 3. 按偏移量 O(1) 解包 (如: 0~3字节是点赞)
        Client-->>Client: 极速返回计数结果 (流程结束)
    else SDS 缺失或损坏 (进入重建战役)
        Client->>Client: 2.1 检查防刷退避策略 (inBackoff)
        Client->>Client: 2.2 检查令牌桶限流 (allowedByRateLimiter)
        
        Client->>Redisson: 2.3 tryLock(等待 200ms, 租期 3s)
        alt 抢锁失败 (门外等了 200ms 还是没抢到)
            Client-->>Client: 抛出 SYSTEM_BUSY 异常 (优雅降级, 防止假0)
        else 抢锁成功 (进门干活)
            Client->>Redis: 2.4 Double-Check (再次 GET SDS)
            Redis-->>Client: 返回 raw byte[]
            
            alt 发现已被排在前面的线程重建好了
                Client->>Client: 惊喜：直接解包解析！
            else 依然缺失 (真正执行耗时重建)
                loop 遍历系统支持的【所有指标】
                    Client->>Bitmap: 2.5 管道批量执行 BITCOUNT
                    Bitmap-->>Client: 返回最底层的绝对真实计数
                    Client->>Client: 将 long 数值转为 4字节，填入 byte[] 白板
                end
                
                Client->>Redis: 2.6 SET 写入完整的 20字节 SDS 结构
                Client->>Redis: 2.7 HDEL 清理聚合桶中多余的增量
                Client->>Client: 2.8 重置该帖子的退避状态
            end
            Client->>Redisson: finally: unlock() 归还钥匙
            Client-->>Client: 返回准确的计数结果
        end
    end
