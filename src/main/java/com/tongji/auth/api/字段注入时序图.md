````mermaid
sequenceDiagram
    participant Spring as Spring IoC容器
    participant BeanA as UserService (字段注入)
    participant Dep as UserRepository (依赖)
    participant Map as 单例池 (Map)

    Note over Spring: 开始创建 UserService Bean
    Spring->>Spring: 1. 获取 Bean 定义
    Spring->>Spring: 2. 推断构造器 (默认无参)
    Spring->>BeanA: 3. 通过反射调用无参构造器<br/>Constructor.newInstance()
    BeanA-->>Spring: 返回空壳对象 (依赖字段为 null)
    Note over Spring: 对象已存在，但未填充依赖
    Spring->>Map: 4. 将早期引用放入三级缓存<br/>(用于解决循环依赖)
    Spring->>Spring: 5. 执行依赖注入阶段 (populateBean)
    Spring->>Map: 6. 查找字段上的 @Autowired<br/>需要类型 UserRepository
    Map-->>Spring: 返回 UserRepository Bean (如已有则取，否则先创建)
    Spring->>Dep: 7. 获取 UserRepository 实例 (可能递归创建)
    Dep-->>Spring: 返回 UserRepository 对象
    Spring->>BeanA: 8. 通过反射 Field.set() 设置私有字段
    BeanA-->>Spring: 字段赋值完成
    Spring->>BeanA: 9. 执行初始化方法 (如 @PostConstruct)
    BeanA-->>Spring: Bean 创建完成，存入单例池
