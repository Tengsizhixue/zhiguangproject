sequenceDiagram
    participant Spring as Spring IoC容器
    participant BeanA as UserService (构造器注入)
    participant Dep as UserRepository (依赖)
    participant Map as 单例池 (Map)

    Note over Spring: 开始创建 UserService Bean
    Spring->>Spring: 1. 获取 Bean 定义
    Spring->>Spring: 2. 确定要使用的构造器<br/>(@Autowired 或唯一有参构造)
    Spring->>Map: 3. 解析构造器参数类型 UserRepository<br/>从容器中查找依赖
    alt 依赖尚未创建
        Spring->>Dep: 4. 递归创建 UserRepository Bean
        Dep-->>Spring: 返回 UserRepository 实例
    else 依赖已存在
        Map-->>Spring: 直接返回已有 Bean
    end
    Spring->>BeanA: 5. 通过反射调用有参构造器<br/>Constructor.newInstance(userRepository)
    Note over BeanA: 在构造器内直接完成依赖赋值
    BeanA-->>Spring: 返回完整对象 (依赖已注入)
    Note over Spring: 此时对象已完全创建，无需单独的注入阶段
    Spring->>BeanA: 6. 执行初始化方法 (如 @PostConstruct)
    BeanA-->>Spring: Bean 创建完成，存入单例池
